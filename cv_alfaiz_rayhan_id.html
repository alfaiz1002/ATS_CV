  • Menerapkan 5 HTTP Security Headers (HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy) untuk memitigasi serangan Man-in-the-Middle, Clickjacking, dan MIME Sniffing.

  • Melakukan uji tolok ukur (benchmarking) performa algoritma OTP (50 iterasi + analisis statistik: Rata-rata, Deviasi Standar, CV%) sebagai dasar pengambilan keputusan implementasi produksi.
